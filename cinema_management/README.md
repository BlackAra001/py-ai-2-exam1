## 🚀 Запуск
Убедитесь, что у вас установлен Python. Запустите программу из корневой папки:
`python cinema_management1/main.py`

## 🛠️ Что умеет программа
Программа работает через консольное меню и позволяет:
1. Добавлять, показывать и удалять фильмы.
2. Добавлять и показывать кинозалы.
3. Создавать сеансы (связывая фильм и зал).
4. Бронировать места, смотреть бронирования и отменять их.

## 📂 Структура проекта
*   `main.py` — главное меню и запуск.
*   `movies.py` — работа с фильмами.
*   `halls.py` — работа с залами.
*   `sessions.py` — создание расписания.
*   `bookings.py` — бронирование мест.

## 📝 Git Workflow
Работа велась по модели Feature Branch Workflow:
*   Каждый модуль разрабатывался в отдельной ветке (feature/movies, feature/halls и т.д.).
*   Все изменения вливались в main через Pull Request.
